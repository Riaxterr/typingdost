Kruti Dev 010 (Remington Gail) Character & Special Alt Code Chart

Kruti Dev 010 Hindi typing is based on the legacy Remington typewriter layout. For complex half-letters (संयुक्त व्यंजन), halant forms, and special punctuation, government exam candidates must memorize the following official Alt code keystrokes on their physical numeric keypad:

Hindi Character Alt Code (Numeric Pad) Standard Key Equivalent Common Exam Words
क्र Alt + 0216 d + Z (क + ्र) क्रम, क्रांति, क्रिया
त्र Alt + 0170 1 (Shift + 1) छात्र, पत्र, चरित्र
श्र Alt + 0217 Shift + R (श्) + Z श्रीमान, श्रम, श्रमिक
द्य Alt + 0180 n + + + p (द् + य) विद्या, विद्यार्थी, उद्योग
द्ध Alt + 0228 n + + + n (द् + ध) शुद्ध, युद्ध, प्रसिद्ध
हृ Alt + 0226 u + + (ह् + ृ) हृदय, ह्रास
